# 棱镜拾光 · Prism Memories

留住每一份闪耀。

基于《偶像大师 闪耀色彩 棱镜之歌》（THE IDOLM@STER SHINY COLORS Song for Prism）PC 客户端制作的本地鉴赏项目。通过独立启动器，重温偶像的剧情、语音、卡牌演出与舞台 MV，体验换衣、走秀、拍照和 OurSTREAM 回放。

**当前版本：v1.1 · Windows x64 轻量包。** 本仓库用于发布功能说明与运行包；下载请进入本仓库的 **Releases** 页面。

> 发布状态：v1.1 运行包保留为 Release 草稿，尚未公开下载；游戏资源与 OurSTREAM 两个数据仓库已公开可用。

## 功能一览

| 功能 | 内容 |
| --- | --- |
| 角色图鉴 | 查看已收录的角色与卡牌资料，播放角色语音和卡牌抽取演出。 |
| 剧情鉴赏 | 浏览已收录的角色、事件、活动及生日剧情。 |
| 舞台 MV | 选择歌曲、角色与服饰，保存并切换多个 MV 编队，播放舞台演出。 |
| 换衣与走秀 | 查看角色服饰与模型，体验已实现的换衣和走秀场景。 |
| 拍照模式 | 配置角色、服饰与拍照场景，使用游戏内相册保存和导出照片；支持七草叶月及其本人换衣、跨角色服饰列表。 |
| 礼物活动 | 展示情人节与白色情人节页面，预设常规参与角色的满好感度，解锁相应长语音等奖励内容。 |
| 叶月与登录演出 | 在启动器中选择七草叶月的服饰，应用于角色页看板、小剧场和签到场景；可调整小剧场与签到的播放方式。 |
| OurSTREAM 回放 | 下载、复用和播放已收录的节目，支持完整性检查、失败重试和损坏分块修复。 |
| 个人资料 | 保存用户名、简介、生日与公开状态，选择 P/S 名片及称号；ID 只显示和复制。 |
| 中文显示 | 集成 scsp-localify 本地化插件，以及配套字体、歌词与文本字典。 |

可见内容以本项目支持版本的收录情况及本地资源为准。部分联动角色只提供已收录的图鉴内容，各模式中的角色与服饰范围并不完全相同。

## 启动器功能

- **资源中心**：复用正版资源、复制到独立目录、增量下载、检查和修复游戏资源，以及管理 OurSTREAM 回放。
- **窗口设置**：提供 720P、1080P、2K、4K 预设，默认 16:9、1080P；支持窗口与全屏模式，并处理系统缩放和窗口位置。
- **演出设置**：选择叶月服饰、首页小剧场与签到演出；签到场景保留角色和演出，不提供实际奖励发放。
- **截图入口**：打开游戏设置中指定的截图保存目录，与 MV 截图、相册导出 PNG 共用。
- **后台下载**：下载窗口可最小化或隐藏；有任务时关闭启动器主窗口会隐藏到托盘，可从托盘恢复或明确退出。
- **维护工具**：检查环境、收集日志，以及自动备份后还原 MV 或全部游戏存档。

本地后台随游戏自动启停，无需手动管理后台进程。启动器和必要运行依赖已随包提供，无需安装 PowerShell 7、Python 或 .NET SDK。

## 运行条件

| 项目 | 要求或说明 |
| --- | --- |
| 系统 | 面向 Windows 10 / 11 的 64 位设备；其他系统及全部 Windows 配置未逐一验证。 |
| 图形性能 | 需要能够运行原 PC 客户端的显卡与驱动；高分辨率和复杂场景对性能要求更高。 |
| 游戏资源 | 复用与本项目兼容的正版资源，或通过启动器下载本包对应的资源。 |
| 磁盘空间 | 完整游戏资源约 25 GiB，另需运行包、存档、照片及所选 OurSTREAM 节目的空间；复制与下载前以启动器提示为准。 |
| 网络 | 下载或修复资源、回放时需要联网；本地已准备好的鉴赏内容可离线使用。 |

当前支持的客户端版本为 **2.18.0**，资源版本为 **20006100**。本项目不会自动兼容后续所有官方更新。

轻量包包含启动器和必要运行文件，**不包含完整游戏资源、OurSTREAM 媒体、个人存档或照片**。本地进度与官方账号进度独立，不与官方账号同步。

## 首次使用

1. 从本仓库的 **Releases** 下载 `PrismMemories-v1.1-win-x64.zip`，完整解压到有写入权限的目录，例如 `D:\PrismMemories`。不要直接在压缩包中运行，也不要只提取 EXE。
2. 运行 `PrismMemories.exe`，按首次使用提示准备资源，或进入 **资源中心 → 设置资源目录**。
3. 选择一种资源准备方式：复用兼容的正版目录，或下载到本包的 `Resources`。具体区别见下一节。
4. 在 **维护工具 → 检查环境** 完成检查，然后点击 **启动鉴赏馆**。
5. OurSTREAM 可按需准备，无需下载全部节目才能启动。需要截图或导出照片时，请先在游戏内设置截图保存位置。

如果 Release 同时提供 `.sha256` 文件，可用于核对下载的压缩包是否完整。首次启动或后台加载时请留意启动器的阶段提示。

## 游戏资源如何准备

### 复用正版资源

已在本机使用官方 PC 客户端的用户，可以选择其资源目录。通常位于：

```text
%USERPROFILE%\AppData\LocalLow\BNE\imasscprism
```

请选择实际存放游戏资源的 `imasscprism` 文件夹。该目录与存放 `imasscprism.exe` 的程序安装目录不同。

版本、资源目录及必要文件检查通过后，可以直接复用。**完整检查提示有缺项，不一定代表无法启动**：官方客户端可能没有下载所有内容，但缺少的具体剧情、模型或演出仍可能无法使用。

希望补齐内容时，先通过启动器将已有资源复制到本包的 `Resources`，再进行增量下载与修复；也可以自行使用官方客户端补齐兼容版本的资源，再重新检查。本项目不会向所选正版资源目录新增或覆盖下载文件。

### 下载到独立目录

默认访问 GitHub 数据仓库。使用固定版本标签与认证索引；已有正确文件继续复用，仅补缺失或损坏项。官方源为隐藏的显式备用项，GitHub 失败不会自动切换官方。

没有可复用资源时，进入 **资源中心 → 游戏资源下载**。下载目标固定为启动器所在目录下的：

```text
Resources\
```

可先复制已有来源中的可用文件，再下载缺失或损坏项，以减少重复下载。托管资源需要完成校验和资源目录生成后才能启用；未完成的下载保留进度，之后可继续。

官方资源版本与本项目不兼容时，请使用支持的版本或等待本项目更新。删除存档、替换零散 DLL 或删除身份文件不能解决版本不兼容。

## OurSTREAM 回放与下载

OurSTREAM 与游戏启动独立，支持两种准备方式：

- **启动器下载**：进入 **资源中心 → OurSTREAM 回放**，选择节目下载，或复用已有媒体并检查、修复。
- **游戏内按需下载**：点击尚未准备好的节目后，先确认是否联网下载。确认框会说明大小和保存位置，默认选择“否”；同意后才提交下载任务。

新增下载固定保存到：

```text
Media\ourstream\
```

下载过程中可在启动器回放窗口刷新查看队列和进度。同一节目重复点击不会创建重复任务。**本版需要整场节目下载完成后，再次点击才能播放，不支持边下载边播放。**

网络检查失败时不会启动节目下载进程，网络恢复后也不会自动重试，需要重新点击确认。游戏内触发的下载会在游戏退出时停止；启动器下载可隐藏到托盘继续，明确退出时停止并保留已完成的分块。

默认及最高并发均为 **8**。重试会复用已验证正确的分块，重新下载缺失或损坏内容；同时保留整包及范围下载的部分传输数据；服务器拒绝范围请求时改用同一 GitHub 包整包下载。已完整下载并通过检查的节目可离线播放。

## 存档、截图与迁移

运行目录中的主要数据位置如下，路径均相对 `PrismMemories.exe` 所在文件夹：

| 目录 | 用途 |
| --- | --- |
| `Config` | 启动器路径、演出等设置。 |
| `Backend/data` | 本地后台存档，包括 MV 编队等状态。 |
| `Client` | 游戏客户端的本地设置与状态。 |
| `Photos` | 游戏内相册索引、原图及缩略图。 |
| `Resources` | 本包下载或复制的游戏资源。 |
| `Media/ourstream` | 本包下载的 OurSTREAM 回放。 |
| `Logs` | 启动、后台、下载及会话诊断记录。 |

游戏内相册可将照片导出为 PNG，保存位置与 MV 截图一致。启动器的 **打开截图目录** 指向此导出目录；`Photos` 中的内部照片文件不是直接查看 PNG 的入口。

缺少允许重建的存档文件时，会生成默认状态。出现编队异常时，优先使用 **维护工具 → 还原存档 → 仅还原 MV**；还原前会自动备份。**还原全部游戏存档会清除本地游戏进度、内部相册和照片**，但保留资源、媒体、已导出的图片和启动器设置。

迁移或更新前，请退出游戏及后台，再备份实际使用的运行目录。不要用新包的默认存档覆盖已有进度；客户端状态不保证跨电脑直接复制后可恢复。首次在新设备使用时，建议从初始化的轻量包开始，并重新选择资源、媒体和截图目录。

## 当前范围与限制

- 项目以内容鉴赏为主，未还原完整的养成、经济、任务、抽卡及联网系统。可观看抽卡演出，不代表实现抽卡玩法。
- Live 节奏玩法、报酬与排行榜未实现；已处理的未实现入口会给出提示。
- 礼物活动提供页面与已解锁的鉴赏内容，不还原任务、抽卡获取道具及奖励经济流程。
- 未将全部联动角色开放到拍照或主页等模式；部分服饰仍遵循原客户端的模式限制。
- 新版本资源不会自动追加到旧包。官方更新后，请先查看本项目 Release 的兼容版本说明。
- 游戏内按需下载的确认、排队与进度反馈已完成定向检查，不同设备与真实网络环境仍需持续验证。
- 文本汉化由 scsp-localify 及其字典提供，个别原生提示可能仍未翻译。

## 常见问题

**为什么检查通过，某段剧情或某套服饰仍打不开？**

启动前兼容性检查与全部资源检查不同。复用目录中可能缺少该内容，在资源下载窗口检查来源；需要修复时先复制到 `Resources`，再补齐。

**为什么 OurSTREAM 提示未准备，确认下载后仍不能立即播放？**

节目需要整场下载并验证完成。请查看下载状态，完成后再次点击；失败时检查网络并重新确认或在启动器中修复。

**关闭启动器后，下载为什么还在继续？**

有下载任务时关闭主窗口会隐藏到托盘。请从托盘恢复窗口，或使用“退出”明确结束启动器下载。

**窗口过大或显示不完整怎么办？**

退出游戏，在 **游戏设置 → 窗口设置** 中选择 1080P 或 720P 后重新启动。4K 预设需要相应屏幕空间与图形性能。

**截图按钮打开的目录不正确怎么办？**

在游戏内重新设置截图保存位置。该设置同时用于 MV 截图和相册导出照片，启动器会读取此位置。
